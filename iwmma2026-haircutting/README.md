# Toward Intelligent Robotic Haircutting: From Precision Automation to Vision-Language-Action Models

Interactive talk slides for **IWMMA 2026**, the 15th International Workshop on Mathematical Models and their Applications (Krasnoyarsk, Russia, 27–28 November 2026).

**Ameer Tamoor Khan**, Assistant Professor, PLEN, University of Copenhagen, Denmark

Live page: https://ameertamoorkhan.github.io/html-lab/iwmma2026-haircutting/

## Keys
| Key | Action |
|---|---|
| ← → / Space | previous / next slide |
| **D** | deep-dive drawer (plain language · technical · sources) |
| **O** | slide overview |
| **F** | fullscreen |
| **T** | light / dark theme (use light in bright rooms) |

`#n` in the URL opens slide *n* directly (e.g. `#11`).

## Interactive demos
Hair strand physics with comb and scissors · coverage toolpaths with roughing/finishing · head-motion compensation under latency · speed-and-separation safety · teleoperation latency (TeleHairing numbers) · one-barber-many-robots supervision · VLA instruction → style spec → action chunk (rule-based illustration) · data flywheel · autonomy levels.

Plain HTML/CSS/JS with no build step and no dependencies (Google Fonts are optional).
