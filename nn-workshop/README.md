# Neural Networks Crash Course (workshop slides)

Interactive slides for the hands-on "Intro to Machine Learning: Neural Networks" workshop,
Plant & Environmental Science, University of Copenhagen, 26 November 2026.

Live page: https://ameertamoorkhan.github.io/html-lab/nn-workshop/

Keys: arrow keys to move, **P** = "Where are we?" pipeline, **E** = explain this slide, **L** = switch code between Python and R.
